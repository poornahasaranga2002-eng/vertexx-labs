01 // OVERVIEW & DESIGN CONCEPT

FRICTIONLESS COMMERCE & OPERATIONAL CLARITY

Bridging the gap between an inviting, high-conversion customer storefront and an efficient, clarity-focused warehouse operations management console.

• THE USER PROBLEM & CHALLENGE

Online shoppers often abandon carts when faced with cluttered catalogs, surprise inventory shortages at checkout, and clunky interfaces. Concurrently, warehouse teams struggle with dense, illegible legacy spreadsheets that obscure real-time order priority and stock status.

  • Eliminated cart abandonment through instant live stock indicators.
  • Created a single design language linking customer and warehouse interfaces.
  • Optimized layout reflow so products look stunning across mobile and desktop.

• THE UI/UX DESIGN SOLUTION

Designed a dual-portal ecosystem: a warm, modern customer shopping experience that emphasizes product texture and easy checkout, and a high-efficiency dark-mode administrative dashboard providing warehouse managers with glanceable stock controls and order queues.

// Cozy Comfort — Synchronized Storefront Cart & Distributor Warehouse Store
export class CozyInventoryEngine {
  constructor(initialCatalog) {
    this.catalog = structuredClone(initialCatalog);
    this.cart = new Map(); // sku -> quantity
    this.ordersDispatched = 0;
  }

  getStockStatus(stock) {
    if (stock <= 0) return { label: 'OUT OF STOCK', css: 'out-stock' };
    if (stock <= 4) return { label: 'LOW STOCK (' + stock + ' LEFT)', css: 'low-stock' };
    return { label: 'IN STOCK (' + stock + ' UNITS)', css: 'in-stock' };
  }

  commitCustomerOrder() {
    for (const [sku, qty] of this.cart.entries()) {
      const item = this.catalog.find(p => p.sku === sku);
      if (item && item.stock >= qty) item.stock -= qty;
    }
    this.cart.clear();
    this.ordersDispatched += 1;
    return this.catalog;
  }
}
